# Data Mining Final Projects

- `projects/bert` — news classification with DistilBERT.
- `projects/ecg` — ECG anomaly detection with autoencoders.
- `projects/rnn` — multivariate weather forecasting with recurrent models.
- `projects/vae` — MNIST generation and latent-space analysis with a β-VAE.

Each project folder includes its own setup instructions, code, results notebooks, and report.
